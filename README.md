# DandNoise - Real-time Signal Processing & Visualization

A Python-based interactive tool for generating random signals and applying digital filters in real-time. This application allows you to visualize signal processing techniques including Low-Pass filtering and Kalman filtering with live graph updates.

## Features

- **Random Signal Generation**: Generate various types of random signals (Gaussian, uniform, etc.)
- **Real-time Visualization**: Live graph updates showing signal changes
- **Signal Processing Filters**:
  - **Low-Pass Filter**: Smooth out high-frequency noise from signals
  - **Kalman Filter**: Optimal state estimation for noisy signals
- **Interactive Controls**: Adjust parameters and see immediate effects on the graph
- **Modular Design**: Easy to extend with additional filters and signal types
